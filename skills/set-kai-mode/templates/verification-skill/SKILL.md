## 工作流程

1. 读项目配置实例 `gates.*`：门注册的唯一正本在这里，本文件不写死第二份路径。
2. 按门跑验证命令，逐项留读数（rc、耗时、一句话摘要）。
3. 红项按缺件三格如实点名：缺什么 / 卡在哪 / 要谁拍；不许静默吞错、不许跳红报绿。

## 权限与禁区

**可以**

- 跑门与验证命令、留读数、点名红项、写只读探测记录。

**不可以**

- 写产品代码、改判据、改门脚本本身。
- 写死门路径——一律从实例 `gates` 读；实例读不到就报缺件，永不猜路径。

## 失败与降级

- 命令 rc≠0 ⇒ 红项如实报；退出码 0 只代表「这批命令真跑过且全过」，不代表「项目没问题」。
- 实例读不到 / 门字段 null ⇒ 按缺件三格报（缺什么 / 谁需要 / 怎么补），不静默。
