# 子代理交接契约

主代理给子代理的 prompt 至少包含下面五项。缺项会导致子代理自行猜测，增加返工。

## 1. 通用模板

```text
角色：<explorer|planner|worker|reviewer|librarian|visual-designer>
目标：一句话说明要得到什么结果。
范围：允许查看/修改的目录、文件或模块。
约束：不能做什么，权限边界，不能碰的文件。
输入：已知事实、相关文件、之前的结论、当前日期。
验收：怎样算完成，必须提供哪些证据。
输出：要求的结构和长度。
```

## 2. 各角色必填项

### explorer

- 要定位的行为或符号；
- 搜索起点；
- 是否需要调用链；
- 是否只允许只读。

### planner

- 目标与非目标；
- 已知约束；
- 风险级别；
- 是否需要 reviewer 审查。

### worker

- 明确改动范围；
- 必跑测试或构建；
- 不能触碰的文件；
- 失败时如何上报。

### reviewer

- 模式：`plan_review` 或 `code_review`；
- 对照的目标或 diff；
- 关注点：正确性/安全/测试/兼容性；
- 允许运行的检查。

### librarian

- 要回答的具体问题；
- 需要的来源等级；
- 当前日期；
- 是否要求版本对比。

### visual-designer

- 参考图或现有页面；
- 目标设备与断点；
- 必须遵循的设计系统；
- 输出是规格、代码建议还是资产。

## 3. 返回契约

子代理返回主代理时，必须包含：

1. **结论**：先说结果；
2. **证据**：文件、符号、命令、链接或测试输出；
3. **未确认项**：假设和风险；
4. **建议下一步**：只给一个最合理的下一步。

禁止只返回“已完成”“看起来没问题”这类无证据结论。

## 4. 交接失败的处理

| 失败 | 处理 |
|---|---|
| 缺少范围 | 主代理补范围后重派，不让子代理自行扩大 |
| 子代理越权 | 停止该子代理，切回只读父会话后重派 |
| 输出无证据 | 视为未完成，要求重做或换角色 |
| 连续两次失败 | 交回主代理重新规划，不继续堆代理 |
