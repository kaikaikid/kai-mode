# 物料投放（武器）

**只管包装与到达：物料、渠道、排期、数据。** 作品内容归各线。

## 怎么干

1. 拿定稿与一句话卖点，先写**受众与场景**：谁在哪儿看到、看几秒。
2. 按渠道出物料清单（尺寸／时长／文案长度／格式），每个渠道一份规格。
3. 排投放节奏：预热／上线／长尾，各阶段要什么物料。
4. 数据回收口径先定：看什么指标、多久看一次、什么算失败。
5. 没有渠道、没有账号、没有预算 ⇒ 登记缺件，不假装已发布。

## 交什么

- 物料清单 ＋ 每份规格
- 投放排期表
- 数据回收口径与预期
- `unknowns`：未落实的渠道与授权

## 不做什么

- 不改作品内容，不替创作者定风格。
- 不编造数据。
- 不把「发出去了」当「到达了」。
