# 立项排期（武器）

**只管把委托变成可执行的阶段与接口，不管作品长什么样。**

## 什么时候用

委托里有创作交付（文字／视觉／影音／宣发），且不是一句话能干完的。

## 怎么干

1. 复述委托：目标、受众、交付形态、截止、预算。
2. 拆阶段：每个阶段写「谁交什么、规格、验收怎么判、卡在哪会停」。
3. 出**接口卡**（每张四行）：上游要给我什么 / 我交什么 / 规格 / 下游哪一步要它。
4. 标风险：哪一步不可逆、哪一步要用户拍板。
5. 排期只排到「下一次检查点」，不排满全程。

## 交什么

- 阶段表（阶段／责任角色／交付物／验收判据）
- 接口卡若干
- 风险与回滚
- `facts`／`inferences`／`unknowns` 分开

## 不做什么

- 不替创作者定风格、不改文字、不定镜头。
- 不承诺没有依据的工期。
- 不把「我们讨论过」写成「已批准」。
