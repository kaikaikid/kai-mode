# 替代文本（武器）

**给每张图写一句「它在这里干什么」。** 只给文本，不改页面、不改文档；整页审计走 `accessibility-audit`。

## 怎么干

1. **收图与上下文**：用户上传的图，或活页面上的图（用宿主浏览器工具先看已有标签页，再从页面快照读图片和现有 alt）。上下文包括图出现在哪、周围文字说什么；上传图看不出用途时问一次：「读者在这里应该从这张图知道什么？」
2. **定类型**：信息图、装饰图、功能图（在链接或按钮里）、图内文字、logo、图表或示意图。
3. **先写用途**：这张图在此处告诉读者什么、促成什么；再补读者从周围文字拿不到的必要细节。
4. **按类型写**：
   - 信息图：一句话描述这里真正重要的内容。
   - 装饰图：空 alt（`alt=""`），并说明为什么算装饰。
   - 功能图：写动作或去向，不写画面（链接里的放大镜写「搜索」，不写「放大镜图标」）。
   - 图内文字：原样转写；太长就转写关键行，其余放长描述。
   - logo：写组织名；上下文需要时才加「logo」。
   - 图表或示意图：alt 写关键结论，长描述补坐标轴、主要数值与趋势；只写读得出来的值。
5. **控长度**：默认 125 字符，用户给了上限就按用户的；先砍不服务用途的形容词和细节。
6. **守住不知道**：不猜图里是谁、年龄、族裔、性别或健康状况；看不清就说不确定并问，不编名字、数字或文字。
7. **数一遍**：给每条标字符数，方便用户直接复制。

## 交什么

````text
图 1 — <文件名或页面位置> — <类型>
```
<alt 文本>
```
<n> 字符。现有替代文本（alt／aria-label／title+desc）：「<现有文本，或「无」>」。
长描述（仅图表与长文字）：
```
<数据摘要或完整转写>
```
````

每张图一块，块内是可直接复制的纯文本。

## 判据（通过线）

alt 说出了用途、没超长度、没编事实；看不见图的人读完，不会漏掉重要信息。

## 不做什么

- 不改页面、站点文件或文档；文本交给用户放上去。
- 不逐项描述画面细节而漏掉用途。
- 不给装饰图写 alt，让读屏用户听噪音。
- 不描述与用途无关的隐私细节（儿童正脸、含个人数据的文档）；拿不准先问。
- 不冒充读屏结果；写完就是文本，不等于测过读屏。
