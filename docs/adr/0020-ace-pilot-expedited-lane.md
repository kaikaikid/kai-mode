# 0020 王牌飞行员：用户直连的加急通道（第五岗位）

## Status

accepted —— 2026-10-27 用户拍板「按这版定稿」，并逐问确认两项分叉：
① 王牌做完的票**仍由塔台独占合并 / push / 关票**，王牌只打「加急·待发货」；
② 用户直接对王牌说的活，**简单可免票热修，复杂或影响大的必须开票**。
本 ADR 与 [0003](0003-airport-rebuild-four-roles.md) 并列：0003 管四角色主干，本文只加一条加急车道，不改四角色主干判据。

## Context

四角色把「规划 → 排班 → 施工 → 发货」串成了闭环，但用户随时会插任务：

- 走正常链路要等地勤开票、等塔台下一轮排班，加急没有合法入口；
- 用户临时让某个会话「顺手改一下」时，往往没有票、没有排班、没有审查、没有日报——
  这段活在账面上**不存在**，正是本项目要治的「记录空缺的脏数据」；
- 把加急硬塞进 main / deputy 日表，又会和机长的滚动消费、塔台的排班节奏互相踩。

所以需要一个**用户日常可以直接对话**的角色：入口短、能自己接活，但所有动作仍落在同一套记录面上。

## Decision

### D1 岗位与入口

| 角色 | 口令 | 技能 | 唤醒 | 定位 |
|---|---|---|---|---|
| 王牌飞行员 | `/王牌飞行员` | `skills/ace-pilot/SKILL.md` | **仅人工**（[0010](0010-role-wake-fence.md) 不变） | 用户直连的加急执行面；与机长同权同流程，只换入口、车道、票源与名额 |

- kai-mode 只推荐命令，不自动拉起；地勤 / 塔台 / 机长也不得唤醒它。
- 它不是「第六个机长」：不参与塔台排班，不从后备池取票，只做**用户点名**的活。

### D2 车道与写者

- 车道文件：项目配置 `paths.day_tables_dir` ＋ `day_table_pattern` 的 `-ace.md`（`paths.lanes` 增加 `ace`）。
- **唯一写者＝王牌自己**。塔台不写 `-ace.md`，地勤不写 `-ace.md`；塔台只读它来发货。
- **排队正本＝票标签 `ace-queue`**，不是日表行。王牌启动时把带标签的开放票写进当天 `-ace.md` 再开工；
  日表是**执行视图**，不是队列本身。这样「地勤决定进不进王牌队列」只动标签，不碰别人的日表。
- 机长 / 副机长的 `-main.md` / `-deputy.md` 仍只由塔台写，判据不变。

### D3 地勤开票后的三选一

地勤开完票，向用户给三选一（一次一问、推荐项排第一）：

| 选项 | 地勤动作 | 给用户的回话 |
|---|---|---|
| 现在让王牌做（推荐给真加急） | 给票打 `ace-queue` | 「请执行 `/王牌飞行员`」 |
| 进王牌队列 | 给票打 `ace-queue` | 「已进王牌队列，稍后执行 `/王牌飞行员`」 |
| 等塔台正常排班 | 不打标 | 「等塔台下一轮排班」 |

- 前两项机制相同（都是打标），差别只在用户现在起不起会话——**地勤不代拉角色**（0010）。
- 地勤仍不写日表、不派施工、不 push；它只多了一个「打 / 不打 `ace-queue`」的开关。
- 用户也可以绕过地勤，直接对王牌说活；入口见 D5。

### D4 反双排（塔台侧）

- 塔台后备池排除带 `ace-queue` 的票。
- 若某张 `ace-queue` 票已经出现在 `-main.md` / `-deputy.md`：塔台**删掉自己那张表里的行**并备注「转王牌」——
  塔台是这两张表的唯一写者，删自己的行不越权，也不碰王牌的表。
- 王牌开票时**必须**同时打 `ready-for-agent` 与 `ace-queue`；漏打 `ace-queue` 视同普通票，塔台可正常排班（失败不静默：王牌在票面自查项里点名）。

### D5 接活分诊：热修 / 开票

用户直接对王牌说「做这个」时，王牌先分诊，**二选一，不先做后补**：

**热修（免票）**——以下四条**全部**满足才走：

1. 改动落在单个文件（最多两个），且是纯文案 / 样式 / 配置 / 一行内逻辑修正；
2. 不动接口、数据库 schema、权限模型、依赖版本；
3. 不删除任何文件；
4. 用户明确说「直接改 / 热修」。

热修仍需四件记录，缺一不可：

- 独立 git worktree ＋ 分支 `hotfix/ace-<YYYYMMDD>-<n>-<slug>`；
- 新上下文轻量审查，判词首行 `verdict=pass|fail`、第二行 `ac=1/1`，证据一行 `file:line`；
- 增量提交（不攒大提交）；
- 当天 `-ace.md` 一行 `H-<YYYYMMDD>-<n>`，备注写 `branch=… commit=… verdict=pass`；
  塔台 push 后王牌核实 commit 已进 `origin/dev`，才删行；
- 当日日报（`paths.handoff_dir`）一行「热修：<一句话>（分支 / commit）」。

**开票**——任一条不满足，或用户不说「热修」，王牌**自己补一张最简票**（六件套：目标 / AC /
允许修改 / 禁止修改 / 验证命令 / 依赖与红线），挂开放里程碑（没有就建一枚「加急通道」），
打 `ace-queue`，然后按单票闭环施工。

- 免票不等于免记录：热修的四件（分支、判词、日表行、日报）就是它的账。
- 不建票、不写行、不留判词的「顺手改」一律禁止——那正是本 ADR 要消灭的形状。

### D6 名额

- 王牌同一时刻**只带 1 张**（票或热修都算一张）。
- 理由：加急买的是**延迟**不是吞吐；单写手最干净；王牌是单一对话会话，同时开多张只会把用户晾在中间。
- 做完一张立刻接下一张（滚动消费自己的车道）；待发货不占名额，与机长同口径。

### D7 发货：塔台独占不变

- 王牌**不**合并、**不** push、**不**关票；塔台仍是唯一持有者（0003 D5 不动）。
- 王牌 `pass` 后：有票的票面写「加急·待发货」；热修在日表行备注 `verdict=pass` ＋ 分支 ＋ commit。
- 塔台每轮**先发加急批**：`加急·待发货` 的票与 `-ace.md` 里带 `verdict=pass` 的热修行排在本轮最前；
  热修无票可关，只合并推送并在日报记一行。
- 王牌在票面 / 日表行里写「加急」不等于改优先级规则：塔台仍按判词与合并门禁发货，不替审查下结论。

### D8 看板

- `paths.lanes` 增加 `ace`；`flight-info` 的日表源默认包含 `*-ace.md`。
- 看板上王牌车道的掌机显示为 `ace`；它的「待发货」与机长的待发货同一段渲染，塔台推角标不变。
- 看板仍只读，不改票面 / 日表。

### D9 唤醒、停等与裁决

- 唤醒：**仅人工**（0010 不改）。定时器仍只唤醒塔台。
- 「停」与「等」、续跑指针、停点闭集、取舍派裁决子代理：**全部照机长**（[0018](0018-in-run-adjudication.md)／[0019](0019-stop-versus-wait.md)），
  包括「无续跑指针的收场＝停摆」。
- 王牌是用户当前会话时，可以不落指针直接答话；**一旦开始按票施工**，就回到协议口径。

### D10 记录面（闭环的四件）

| 活 | 票 | 王牌日表 | Issue 评论 | 分支提交 | 日报 |
|---|---|---|---|---|---|
| 有票加急 | ✓ | ✓（票号行） | ✓（开工 / 施工 / 审查 / 待发货） | ✓ | ✓ |
| 热修 | — | ✓（`H-` 行） | — | ✓ | ✓ |

- 热修少的是「票」这一件，不是「记录」；四件里任一缺失＝这活没发生完，不许对外说做完了。

## Consequences

- 正面：用户随时插的活有了合法入口；加急不再靠「某个会话顺手改」，记录空缺被堵住；
  push 权仍只有一个主人；四角色主干判据一条没动，新增面只在「入口＋一条车道＋一个标签」。
- 负面 / 风险：
  - 多一个岗位要维护，人格 / 唤醒 / 看板三处都要认它；
  - 热修是**受控例外**，四条门槛靠王牌自判，判宽了会退化成「先做后补」——靠日报与日表行可审计，塔台发货前核对；
  - 王牌与塔台都可读 `-ace.md`，但只有王牌写；塔台若顺手写了行，就是越权，按 0003 D5 处理。

## 明确不做

- 不给王牌第二份 push / 合并 / 关票权。
- 不让塔台排王牌的班，也不让地勤写王牌日表。
- 不恢复「先做后补票」；不把热修门槛放宽到「用户说急就行」。
- 不让王牌替机长消费 main / deputy 日表，也不让机长替王牌消费 `-ace.md`。
- 不自动拉起任何角色（0010 仍有效）。

## 验证（判据级）

- 新项目初始化后 `paths.lanes` 含 `ace`，`-ace.md` 能被 `captain-preflight --lane ace` 识别。
- 看板（flight-info）刷新后出现王牌车道；`board.json` 的 `sources` 仍全绿或如实降级。
- 地勤三选一：选前两项后票面带 `ace-queue`；选第三项不带。
- 塔台排班：后备池不含 `ace-queue` 票；已混入 main / deputy 的会被删行并备注「转王牌」。
- 热修：日表有 `H-` 行、分支存在、判词可读、日报有一行；塔台推送后王牌能删行。
- 唤醒围栏：`docs/canon.json` 的 `wake-fence` 扫描仍绿（新技能不得出现自动拉起措辞）。
