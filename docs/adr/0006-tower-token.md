# 0006 塔台令牌：跨进程互斥与拉起权限收紧

## Status

accepted —— 2026-10-23 kaikaikid 口径定稿。**判据来源：kaikaikid 2026-10-23 口径**：「拿到令牌才是塔台，以免一堆塔台；现阶段不允许机长直接唤醒塔台」，本文照落不改方向。与 [0003](0003-airport-rebuild-four-roles.md) D1/D5 互指（0003 D1 已加演变注指回本文 D3）；令牌路径与缺件口径按 [0004](0004-project-config-schema.md) D2/D4。执行清单住[塔台技能](../../skills/塔台/SKILL.md)「0. 抢令牌」，本文只记裁决，不承载第二份细则。

## Context（威胁模型）

塔台可被三路拉起：30 分钟定时器、人工 `/塔台`、kai-mode 入口判断。三路之间没有协调：定时器上一轮没跑完，下一轮到点又起；人工 `/塔台` 撞上正在跑的定时轮；kai-mode 判断拉起再叠一路。两个塔台同时醒＝同时写日表（后写覆盖先写）、同时发货＝**双 push 双关票**——0003 D5 的「塔台独占 push」只是**规则层**单点，进程层没被钉住，独占权靠不住。需要跨进程互斥：同一项目仓同一时刻最多一个塔台在飞。

## Decision

### D1 令牌与流程

- 令牌＝项目仓运行态下的独占锁文件 **`tower-token.json`**，落在项目配置实例 `paths.state_dir` 下；路径运行时从实例读，**无实例按 [0004](0004-project-config-schema.md) D4 报缺件三格（缺什么/谁需要/怎么补），不猜路径**。
- 令牌内容三件：**持有人标识**（会话/任务名）、**取得时间**、**最近心跳时间戳**。
- 流程：塔台实例启动**第一件事＝抢令牌**——无令牌、或令牌心跳已过期 → 写入自己信息即持牌；令牌有效（他人持牌且心跳未过期）→ **退位**：不排班、不发货，输出一行「已有塔台在飞（持牌人 X，心跳 T），本轮退出」即收。抢牌先于起手、先于发货：排班发货等一切动作都在持牌之后。

### D2 心跳与接管

- **心跳**：每轮工作开始续约一次；轮内长动作（合并、推送）之间可再续。
- **过期阈值**＝错过两个轮巡周期（默认 **65 分钟**；按实例 `tower_cron.interval_min` 推导：interval×2＋5 分钟缓冲）。
- **释放**：正常收工显式释放（删令牌文件或写 `released`）；异常死亡不补写，靠心跳过期被下一任接管。
- **接管记录**：每次易主在当日 handoff 日报（`paths.handoff_dir`）留一行——谁接谁的班。

### D3 拉起权限收紧

- **现阶段机长/副机长不得拉起/唤醒塔台**（后续可评审放开）：需要塔台时把交付/卡点写进 Issue 评论与播报，由下面三路来拉。
- 允许的拉起方＝**人工口令、kai-mode 入口、30 分钟定时器**三路；三路并发靠 D1 令牌互斥。0003 D1「四角色均可手动拉起或由 kai-mode 判断拉起」对塔台由本条收紧（0003 D1 已加演变注）。

### D4 现阶段口径与放开条件

- 现行口径：**拿到令牌才是塔台**。无牌即退，没有「第二个塔台等一等」的灰区。
- 放开条件：出现可评审的塔台间协商机制（如排队让牌）并经用户拍板，才允许机长侧唤塔或第二实例等待；在此之前不放开。

## 与既有判据的关系

- **与 0003 D5**：不冲突——D5 说塔台独占 push（规则层单点），本令牌把独占钉到进程层；令牌是 D5 独占权的物理执行，不改变归属。
- **与 0003「清退令牌」**：0003 清退的是旧机场机器的**在岗令牌**（两层归属相反、不可复现的在岗判定与租约机制）与「运行态 json 作为恢复态」（D6 断点三件套口径）。本令牌是**单轮互斥锁**：语义（防双实例）、生命周期（单轮、心跳过期即让）、用途（不进断点三件套、不当恢复态）都不同，不复活旧机制；判据来源晚于 0003，冲突处以本文为准。
- **与 0004**：路径从实例 `paths.state_dir` 读（D2 字段表），缺件按 D4 三格报；阈值推导用 `tower_cron.interval_min`——技能正文不写第二份默认路径（「一个语义一个家」）。
- 执行面分布：抢/续/退位清单住[塔台技能](../../skills/塔台/SKILL.md)「0. 抢令牌」；拉起禁令住[机长](../../skills/机长/SKILL.md)/[副机长](../../skills/副机长/SKILL.md)围栏＋[loop-protocol](../../loops/loop-protocol.md) §十二；拉起人名单住 [kai-mode 技能](../../skills/kai-mode/SKILL.md)；定时器侧一句话住 [set-kai-mode](../../skills/set-kai-mode/SKILL.md)「3.」。
