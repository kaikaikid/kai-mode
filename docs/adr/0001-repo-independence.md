# kai-mode 是独立仓，自有 ADR 系列

本仓是跨项目通用的技能与剧本仓，独立于任何项目仓（README 已于 2026-10-22 定下这个口径，但当时裁决权仍让给了项目仓）。现在本仓有了自己的远端（`kaikaikid/kai-mode`，private），继续沿用"引用别处 ADR 作正本"会让本仓的决策仍然写在外仓里。

**决定：** 本仓的裁决记在 `docs/adr/`，编号从 `0001` 起，**不续接项目仓的 ADR-01xx 序列**。项目仓的 ADR 不约束本仓；本仓也不为项目仓代存 ADR 正本。历史文档（`MIGRATION.md`、`loops/loop-protocol.md`、若干 `skills/*/SKILL.md`）里对 ADR-0130/0137/0140/0141 的引用是**迁移期遗留**，读的时候当作出处说明，不当作本仓的现行裁决；它们与本 ADR 的冲突逐个清理前，以本 ADR 为准。

代价是两仓可能各写一份相近的裁决。这是接受的：宁可重复而各自明确，也不要单一正本却让本仓的行动受外仓条款摆布。
