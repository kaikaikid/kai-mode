# 入口、参谋与安装剧本

> 一句话：把一句话需求路由到正确的岗位；把框架装到宿主；把会话压成交接件。

## 命令

| 命令 | 做什么 | 不做什么 |
|---|---|---|
| `/staff` | 需求大时由康娜调用：拷问 → 定稿 → 拆票草案 → 规划表 | 不执行具体活 |
| `/set-kai-mode` | 缺口扫描 → 只装缺的 → 回执 | 不做日常施工 |
| `/upgrade-kai-mode` | 升级清单 → 拍板 → 备份 → 回写 → 验收 | 不做首次安装、不碰项目数据 |
| `/handoff` | 把会话压成交接文档 | 不复制 issue／ADR／diff 正文 |

## 技能

- `bridge`：主 AI 人格（康娜）的方法正文，也是默认入口。
- `staff`：参谋部，需求大时由康娜调用的规划方法。
- `fleet`：执行内核（住 `engine/`）。
- `set-kai-mode`：安装、配置实例、缺件登记。
- `upgrade-kai-mode`：把已装配的旧版升到新版（只升漂移项，带备份与回滚）。
- `kai-handoff`：交接与跨 agent 派活。
- `harness-audit`：语义审计（手动安装）。
- 原则合集（`principles`）：一次一问、只问可见与红线、一个语义一个家、缺件如实登记、能测就不问、仪式随规模塌缩、输出结构（L1–L4）。
