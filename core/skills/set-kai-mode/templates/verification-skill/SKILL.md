> 所有 `<...>` 占位由项目自己填实——**尤其是验证命令：生成端只探技术栈、不猜命令**。

## 范围与权限

**可以**

- 跑门与验证命令、留读数、点名红项、写只读探测记录。

**不可以**

- 写产品代码、改实现、改 AC、改判词、改门脚本本身。
- 写死门路径——一律从实例 `gates` 读；实例读不到就报缺件，永不猜路径。

## 输出契约

逐条 AC 一行：`AC 编号 | 命令 | 读数 | 证据路径`；末尾给 `verdict=pass|fail`。
证据不足写 `unverified`，不要用“看起来没问题”代替。

## 失败与降级

- 命令 rc≠0 ⇒ 红项如实报；退出码 0 只代表「这批命令真跑过且全过」，不代表「项目没问题」。
- 实例读不到 / 门字段 null ⇒ 按缺件三格报（缺什么 / 卡在哪 / 要谁拍），不静默。

## 交棒

把判词与证据指针写进 Issue 评论；细节留在测试输出与票面。
