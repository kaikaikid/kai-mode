# 第 3 步：把康娜设为默认入口

用户要求「忘了触发也默认康娜」。两个落点，按「这套默认要不要跨项目」二选一：

| 落点 | 适合 | 做法 |
|---|---|---|
| 项目级（默认） | 不同项目要不同默认入口；多人共用一台机 | 项目 `CLAUDE.md` / `AGENTS.md` 末尾加一段 |
| 全局／用户级 | 单人、多项目同一套工作方式；换项目不想重装 | 用宿主的用户级默认入口口；**不手改宿主自动生成的文件** |

**优先级：项目级 > 全局级。** 两处都写了按项目那份，不叠加、不合并。

## 正文段（两处共用同一段，只落一份）

正本就是这一段，宿主侧文字**由它抽取**、不另手写（手写必漂）。装完复校：宿主文件里这段与下面
 fenced 块逐字相同，且该文件里 `## 默认入口` 只出现一次。

```markdown
## 默认入口

没点名其它技能、也没打斜杠命令时，一律按康娜执行：先读宿主的 `gold` 技能全文，再按其流程处理。
本仓没装该技能就按普通会话处理，不报错、不猜路径。
```

## 全局级的三条硬规矩

1. 宿主有「默认 Agent」设置的，优先用它，别拿文本文件糊。
2. 带生成器标记的文件（整份由别的工具生成）**一律不手改**——下次同步会被盖掉，
   甚至把人的改动写回生成器。写全局前先确认这份文件是不是生成物。
3. 确认是生成物 ⇒ 改**生成器那份正本**，再用生成器的写入口重生成；命令与落点住
   `adapters/<宿主>.md`，本节只定流程。一个生成器口常常同时喂多家（本机实测见
   `adapters/qoder.md`），所以改完必须**逐家回读**，不许拿「已写共享指令」当三家都到位。

宿主支持 `UserPromptSubmit` 钩子时，可另装一条只读提示钩子，把上面这句作为附加上下文；
钩子只提示、不改用户输入。宿主没有钩子口 ⇒ 只靠指令文件，登记为软约束。

**全局装必须带兜底句**（正文段最后一句）：全局生效后，没装本框架的仓也会读到这段，
不许因此报错、瞎找技能或改变行为。精简措辞时**只可压字、不可删这一句**——它是全局唯一的保险。

## 验收

- 新开一个会话，直接说「现在到哪了」，不打任何斜杠命令，应能读到 `fleet status` 并按康娜回报。
- 全局装再加一条：在**没装本框架的仓**开一个会话，不报错、按普通会话处理。
- 走生成器口写全局时，逐家三项读数：该文件里 `## 默认入口` 计数＝1、兜底句在位、
  与正本 fenced 块逐字相同；改前先留生成器旧文本与目标文件的备份。
