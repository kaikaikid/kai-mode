怎么读这张表

“命令”一栏是 — 的技能，不是口令：它们随角色或会话自动带入，比如 loop、studio 和六条原则。真正要你说出口的，是“触发口令”那一栏。

五类怎么分

机场体系 · 7

地勤、塔台、机长、副机长、二副、王牌，以及单票闭环协议 loop。

入口与安装 · 10

总入口、安装、交接、语义体检，外加六条原则。

文娱集团 · 7

共享协议，加企划、主笔、主美、导演、终审、宣发六岗位。

支持能力 · 4

想法池、事故处置、运维手册、航班信息看板。

方法库 · 7

fork 自上游的通用方法：kai-tdd、kai-code-review、诊断、领域建模、安全审计、拆票、写 agent 文档。kai- 前缀、随插件安装、可微调。

给技术同事：这张表怎么来的

数据由 python scripts/manual-gen.py 生成：插件顺序取 .claude-plugin/marketplace.json，技能名 / 版本 / 描述取各 skills/*/SKILL.md 的 frontmatter，斜杠命令从各插件 commands/*.md 反查。

“一句话”优先读 manual/skills-plain.json 的人话覆盖；没覆盖的取 description 首句。生成结果写到 manual/assets/skills-data.js，页面只负责渲染、分类与筛选。

技能总数与 manifests/plugins.lock.json 对不上时，生成脚本会返回 1；先修清单，再改手册。
